# Desenvolvimento Web - Projetos da Faculdade

Repositório com exercícios e páginas desenvolvidas na disciplina de Desenvolvimento Web durante o curso de Tecnologia em Análise e Desenvolvimento de Sistemas (IFSP São Carlos).

## Arquivos e Conteúdos

- **formulario_usuarios.html**: Página estruturada com formulário de cadastro, campos variados de entrada de dados e validações semânticas de HTML5.
- **pagina_rede_social.html**: Layout simulando a interface de um feed/perfil de rede social com estrutura semântica.
- **posicionamento_css.html**: Exercício prático focado em propriedades de estilização, alinhamento e fluxo de posicionamento com CSS.
- **tabela_sudeste_sul.html**: Estruturação de dados tabulares utilizando tags semânticas de tabela em HTML com dados regionais.
